# ADRs

Architecture Decision Records. Each ADR captures one decision that is now
true about this codebase, written after the corresponding RFC is approved
and implemented.

## Status definitions

- **proposed** — written but the implementation has not landed yet
- **accepted** — the decision is in effect
- **deprecated** — no longer the recommended approach but still in use
- **superseded** — replaced by a later ADR (`superseded_by` populated)
